# V3 设计：逐字 min 聚合判别头（纯设计待办，未实施）

> 状态：仅设计。GPU 冻结中，实施需用户发话。
> 前提阅读：`supervision-analysis.md`（监督信号病根）、`progress.md` v2.2 终局一节。

## 1. 要治的病（证据链）

v2.2 终局（官方 1000 图）：recall@0.5 0.8893 / auroc 0.9433 / fp 0.1001。
fppeek：63 个 fp 中 61 个是 distr 型——**单字符变异近邻**（08504→08534、F8676→F8646），
fp 分数 mean 0.722 / max 0.998，比一半真目标还高。

病根是"不看全体"，结构 + 监督双重作用（`core/model.py` 现状）：

- **结构**：score = fuse(cos_map, xcorr_maps)。xcorr 是整串模板 T(8×48) 逐通道相关后求和——
  10 字串对上 9 个，相关能量仍有 ~90%，一个错字几乎不扣分；cos 全局向量更是 bag-of-glyph。
- **监督**：逐格 BCE 只教"这个格子附近像不像查询串"，没有任何信号教"每个字都必须对"。

检测侧已解决（找得到、框得准：recall_iou0.3==0.5，钳位根除，三级分工正常）。
V3 只动判别：**把"整串相关求和"改成"逐字相关取最小"——任何一个字对不上，分直接死。**

## 2. 设计边界（用户定的原则，不可违）

- 仍是 mask 驱动的**检测**任务：不引入字符类别语义，不做 0-9 分类器，不识字。
- 查询仍是整串一次性输入（24-6-1234 作为一个查询），不做"逐字检索再合成"。
- 部署契约优先：全静态 shape，无 attention / 动态 Gather / GridSample，ONNX + pnnx→ncnn 双友好。
- 参数预算 ≤10M（现 2.4M），推理开销增量控制在可忽略级。

## 3. 核心思想

```
score(y, x) = softmin_over_k[ R_k(y, x + k·Δ) ]
```

- R_k = 第 k 个查询字的模板与场景特征的互相关响应图（每级特征一份）。
- Δ = 字距（feature 像素，见 §5，与尺度解耦后是常数）。
- softmin = -τ·logsumexp(-R/τ)，训练用软（梯度可达最差字），推理可硬 min。
- 语义：候选位置的得分 = 整串里**匹配最差那个字**的得分。单字变异近邻结构上被判死刑。

## 4. 关键决策：字边界从哪来

模型只看光栅，不知道哪里是一个字。两条路线：

### A2（推荐）：逐字光栅输入

App 渲染端本来就认识这串字，逐字渲染零成本：

- 输入契约：`scene (1,3,416,416)` + `chars (1,12,1,64,40)` + `nchar (1,)`。
  每个字渲染进 64×40 槽（glyph 等比缩放到槽内，白底黑字），最多 12 字，余槽全白。
- 字编码器（共享权重的小 CNN，~150K 参数）：64×40 → (Cc, 8, 5) 逐字模板，batch=12 一次算完。
- nchar 与常量 arange 比较出 valid mask（Less+Cast，纯静态算子），无效槽在 softmin 前加大偏置屏蔽。
- 优点：字边界干净、无邻字串扰、渲染端逻辑反而更简单（不用整串 getbbox）。

### A1（回退备选）：定距整串渲染 + 静态切片

- 不改输入契约（仍 (1,1,64,384/480)），渲染约定改为定距槽位：每字独占 40px。
- MaskEncoder 输出 T 的列按槽宽/8 静态切片即逐字模板。
- 缺点：多层卷积感受野 ~30px，邻字特征渗入切片，逐字响应不独立（对 min 判别有害不致命）；
  优点：插件/App 输入零改动。**仅当 A2 的 pnnx 转换撞墙时启用。**

## 5. 逐字响应与聚合（场景侧）

场景管线不动：BackboneV2 + NeckV2 + FiLM（w 改为逐字嵌入的 masked-mean）+ DFL 回归分支（97ch 布局不变，score 通道语义换源）。

- 每级特征图投影出相关特征（同现 `corr_proj`），逐字模板双线性缩放到该级字高尺度：
  核从"整串 (6,36)"变成"逐字 (sh, sw_char)"，sh∈{4,6,8} 对应字高 16/24/32px（s4 级）。
- 字距常数性：槽宽 40px / 查询高 64px = 0.625。模板缩放到 sh 行时，
  **Δ = 0.625·sh（feature 列数），与层级无关**。sh=4 → Δ=2.5 列。
- 非整数 Δ + 场景字距抖动：先在 R_k 上做小窗 max（3×1 maxpool），再按四舍五入偏移静态切片取值——
  全部是 Slice/MaxPool，ncnn 原生算子。
- 融合：softmin 图与 cos_map concat 过 1×1（沿用现 fuse 结构），cos 保留粗先验护 recall，
  min 头负责精度。

**计算量**：逐字核面积 ~4×2.5=10/字 ×12 字 ≈ 120，现整串核 6×36=216——**反而更小**。
字编码器一次性开销可忽略（12 张 64×40 小图）。推理时长预期与 v2.2 持平。

## 6. 训练与数据

- **synth 改造**：target 逐字渲染并记录每字框（PIL 逐字 draw，简单）；
  字距 jitter ±10% 增广（模拟真实字体 pitch 差异）。
- **新增逐字辅助监督**：R_k 在字 k 真值中心处 BCE 为正——密集监督信号，
  直接教逐字判别（v2.2 只有整串格级监督，这是信息量升级）。
- hard-neg（一字之差串）保留现比例：min 结构 + 逐字 aux 双管齐下，fp 预期数量级下降。
- **新增 mutation 评测门**：query Q vs 画面 Q'（一字之差）成对构造，
  要求 Q' 无 ≥0.5 框。验收门槛：mutation-fp ≤2%，官方 1k recall@0.5 ≥0.95，fp ≤0.03。
- 规程：epochs 30 / eval_every 5（新规程），best.pt 机制不变。
- 课程实验项：softmin 早期梯度集中在最差字可能不稳，前 5 ep 用 mean 聚合 warmup 再切 softmin。

## 7. 部署契约变化（A2）

- in1：`(1,1,64,384)` → `chars (1,12,1,64,40)` + `nchar (1,)`；输出 3×(97,H,W) 不变，**decode 零改动**。
- 新算子清单（全部 ncnn 可表达）：logsumexp 拆 ReduceMax/Exp/Sum/Log；常量 arange+Less→mask；
  静态 Slice/MaxPool；逐字 xcorr 沿用现 grouped-conv 动态核写法。
- pnnx 转换后照旧人工核 Reduction axes（convert_ncnn.sh 既有坑位）。
- App 侧：`mask_render.dart` 改为逐字槽位渲染（更简单）；插件 `setQueryMask` 签名改传 12 槽字节流+字数。

## 8. 风险登记

| # | 风险 | 缓解 |
|---|---|---|
| R1 | 真实字体字距 ≠ 0.625 倍字高，对齐漂移 | 窗化 max + synth pitch jitter ±10% |
| R2 | recall 可能掉（min 严格化，训练 13.6% 毒遮挡遗留习惯） | 门槛 recall≥0.95；不达标调 τ 或退方案 B |
| R3 | 逐字 aux 依赖 synth 字框准确 | 合成器改造后先跑审计流程（复用 failpeek  tooling） |
| R4 | pnnx 对 5D 输入/比较算子转换翻車 | 回退 A1（整串+切片） |

## 9. 方案 B（独立回退路径）：ROI 判别头

v2.2 检测头照旧出候选（召回不动），加轻量 verifier：候选框 ROI 池化到固定 16×64 特征，
与逐字嵌入做逐字比对重打分，只覆盖 top 框。工程可插拔、训练分阶段；
代价是多一个 ROI 头 + 二次推理。A2 失败或 recall 不达标时启用。

## 10. 实施顺序（发话后）

1. synth：逐字框记录 + pitch jitter + mutation 评测集构造
2. model：字编码器 + min 头（A2），v2 头保留开关做 ablation
3. toy 验证（cenprobe 式）：100 对 mutation 看分数分离度，不达标不进全量
4. 全量 30ep + eval5 → 过 §6 门槛
5. ONNX/ncnn 导出对拍 → 插件 in1 契约改造 → App 逐字渲染 → 真机回归（phone-test-plan.md）

# 实施定稿（2026-02-26，以此为准，§4/§5 的 A2/A1 方案已被取代）

落地时对齐方案收敛，比原设计更简：

- **单画布槽位渲染**：mask 仍是一张 (1,1,64,384) 光栅，渲染约定改为 12 槽 × (64×32)
  逐字入槽 + 整串居中 + 奇数串尾补空槽（偶数化）。模型内 reshape 最后一维成 (12,32)
  即逐字切片；槽有效性 = 墨迹均值在线判定。**dataset / labels.jsonl / 插件输入个数零改动**。
- **整数常量偏移表**：槽距/字高 = 0.5，尺度 sh∈{4,8} → 字距恒为偶数列（2/4），
  off_j=(j-5.5)·sh/2 对任意串长奇偶皆整数——对齐 = 纯静态 Slice/MaxPool，
  训练与部署同一张图，无动态 Gather/GridSample。
- **奇数串半槽偏差**由容差 maxpool 恰好吸收（sh4: (7,3) ±1列=半字距；sh8: (11,5) ±2列=半字距，
  纵向兼吃 ±12° 旋转的 ±0.6 字高散布）。
- **不逐字 aux 监督**：min 结构梯度天然导向最差匹配字（正样本抬最低、hard-neg 压最低），
  MVP 期不引入辅助损失（留作实验项 E2）；mutation 评测集也不需要 synth 出新数据——
  tools/v3probe.py 直接用现成 val 场景 + 现场变异重渲 mask。
- **实测**：参数量 2.03M（比 v2.2 的 2.40M 小），计算量 ≈ v2.2 的 1.3 倍，bs16 显存 2.2G。
- synth 改动面：仅新增 render_mask_slots + gen_code 长尾限长 ≤12；场景侧零改动
  （字距 ±15% 抖动已有）。
